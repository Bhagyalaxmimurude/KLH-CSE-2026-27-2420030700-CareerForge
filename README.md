## Abstract

CareerForge – AI-Powered Career Development Platform with DevOps, DevSecOps & MLOps Pipeline is a comprehensive web-based application designed to support students in preparing for internships and employment opportunities through intelligent career guidance and modern software engineering practices.

Many students face challenges in evaluating their resumes, identifying skill gaps, preparing for technical interviews, and tracking their learning progress. CareerForge addresses these challenges by providing an integrated platform that combines artificial intelligence, secure software development, cloud technologies, and machine learning operations to create a personalized career development experience.

The platform allows students to register securely, create and manage personal profiles, upload resumes, and receive AI-powered resume analysis with suggestions for improvement. Based on extracted skills and resume content, the system recommends learning resources, certifications, and personalized career roadmaps. It also provides AI-assisted interview preparation, performance tracking, and a dashboard for monitoring career progress.

The project follows Agile Software Engineering principles, with requirements organized through user stories and a prioritized product backlog. Scrum methodology is used for sprint planning, incremental development, testing, and continuous feedback. Git and GitHub are used for version control and collaborative development.

DevOps practices are implemented using Docker and GitHub Actions for CI/CD, with AWS used for cloud deployment. Prometheus and Grafana are used for application monitoring and performance analysis.

DevSecOps practices include Spring Security, JWT authentication, BCrypt password encryption, role-based access control, SonarQube static code analysis, Trivy container vulnerability scanning, and OWASP-based security testing.

The AI and machine learning components use Python, Scikit-learn, Pandas, and FastAPI. MLflow is used for experiment tracking, model versioning, deployment, and lifecycle management. Overall, CareerForge integrates Software Engineering, Agile development, DevOps, DevSecOps, Cloud Computing, Artificial Intelligence, and MLOps into a single secure, scalable, and cloud-ready platform.
